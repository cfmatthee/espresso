# espresso

A Rust based Windows taskbar application that, when active, prevents the computer from sleeping.

## Rules

- Do not change the version numbers in the `Cargo.toml` file. If you want to change the version, explain why the change is required and ask the user if they want to change it.
- Every `unsafe` keyword must have a comment line explaining why the block is marked as unsafe following the opening bracket directly after the unsafe keyword.
- Only change code required to perform the requested tasks. Make the minimum amount of changes required to complete the tasks given to you. Do not change any other code.
